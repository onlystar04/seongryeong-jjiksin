# 성령고 찍신

평범한 OMR 찍기 게임으로 시작해, 각성제의 유혹과 100점의 반전을 겪게 되는 인터랙티브 웹게임입니다. (드라마 〈각성〉 연계 기획)

## 실행
`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 서버나 설치가 필요 없습니다.

## 설정
`index.html` 안의 `CONFIG`에서 바꿀 수 있습니다.
- `DRAMA_URL`: '진실 확인하기' 버튼이 열 드라마 공식 페이지·예고편 주소
- `SOUND_FILES.LAUGH`: 귀신 웃음소리 음원 주소 (비어 있으면 합성음 사용)
- `TEXT`: 게임 속 모든 문구
- `TIMING`: 엔딩 연출 타이밍

## 기술
React 18 (UMD) + htm, Web Audio API, CSS 애니메이션, localStorage(예외 처리 포함)
